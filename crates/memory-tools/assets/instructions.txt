Antes de inventar nombres de relación, jerarquías de clase o axiomas nuevos para memory_reason, comprueba si ya existen: memory_search con path_prefix "ontologies" (type: ontology) para vocabulario compartido, y con type: skill para procedimientos ya documentados (via skill_ingest) que puedan aplicar a la tarea. Si encuentras un documento type: ontology, pásalo como ontology_id a memory_reason en vez de copiar sus axiomas a mano — el servidor los carga y aplica directamente. Si no existe ninguno para el dominio que necesitas, decláralo tú UNA VEZ con memory_commit (ver la descripción de memory_reason para la sintaxis del cuerpo) para que memory_reason lo reutilice por ontology_id en cualquier llamada futura, de cualquier agente. Reutilizar lo ya declarado en vez de redescubrirlo cada sesión mantiene el grafo consistente entre agentes distintos y evita que el mismo hecho quede fragmentado bajo relaciones sinónimas (depends_on vs requires vs needs) inventadas sesión a sesión.
