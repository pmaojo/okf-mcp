Descompone un `spec` ya propuesto (ver `spec_propose`) en tareas concretas, cada una un concepto `type: task` enlazado de vuelta al spec (`[[implements:<spec_id>]]`) con tag `status-pending`. Se crean en un solo lote (no atómico: cada tarea se aplica o se descarta por su cuenta). Para avanzar una tarea después, usa `memory_patch` sobre su `concept_id` cambiando el tag `status-*` (`status-pending` → `status-in_progress` → `status-done`, o `status-blocked`); no hace falta otra herramienta para eso.
